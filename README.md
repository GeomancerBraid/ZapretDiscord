> Один и тот же инструмент могут применять как безопасные, так и вредоносные программы, однако сам WinDivert вирусом не является.
>
> **Фрагмент [`readme.md`](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B) из репозитория [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle)*
>
> Некоторые антивирусы помещают файлы WinDivert в категории инструментов повышенного риска или хакерских средств, после чего удаляют их и отправляют в карантин. В названии обнаружения обычно присутствует `WinDivert` либо `Not-a-virus:RiskTool.Multi.WinDivert`.
>
> Добавьте каталог zapret в исключения антивируса или отключите обнаружение PUA, то есть потенциально нежелательных приложений. Например, в Kaspersky есть параметр "Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда". Исключение лучше настроить аккуратно, но если вы не уверены в своих действиях, отключите детектирование PUA.

## ⚙️ Использование

1. Сначала включите безопасный DNS (Secure DNS).
    * В Chrome активируйте "Использовать безопасный DNS" и выберите DNS-провайдера, отличного от "Поставщик по умолчанию".
    * В Firefox откройте "DNS через HTTPS", выберите режим "Персональный", затем "Выбрать провайдера/поставщика" и вручную укажите URL. Например, `https://dns.google/dns-query`, поскольку Cloudflare может быть заблокирован.
    * Windows 11 позволяет включить Secure DNS в настройках самой ОС. [Инструкция находится здесь](https://remontka.pro/dns-over-https-windows-11/); для Windows 11 этот способ рекомендуется.
    * Владельцам роутеров Keenetic нужно включить параметр "Транзит запросов". Если его отключить, Secure DNS на компьютере может работать неправильно.

2. Загрузите zip- или rar-архив с [последнего релиза](https://github.com/GeomancerBraid/zapret-discord-youtube/releases/latest).

3. Откройте свойства загруженного архива и установите флажок "Разблокировать". При распаковке через 7-Zip или PeaZip этот пункт можно пропустить.

4. Извлеките архив в каталог без кириллицы и специальных символов в пути.

5. Запустите подходящий файл.
    * Для поиска работающей стратегии откройте **`service.bat`** -> `Run Tests` -> `Standard tests` -> `All configs`.
    * Для включения автозапуска выберите **`service.bat`** -> `Install Service` -> *нужную стратегию*.

## ℹ️ Кратко о файлах

- [**`general.bat ...`**](./general.bat) - ручной запуск стратегии.

  Такой запуск удобен для проверки разных вариантов. Результат зависит от множества условий, поэтому **перебирайте стратегии ALT, FAKE и другие, пока не найдёте подходящую для себя**.

- [**`service.bat`**](./service.bat) - автозапуск и дополнительные операции:
  - <ins>**`Install Service`** - добавление выбранной стратегии в автозапуск через services.msc.</ins>
  - **`Remove Services`** - удаление стратегии и WinDivert из списка служб.
  - **`Check Status`** - просмотр состояния обхода и служб, включая стратегию автозапуска и WinDivert.
  - **`Game Filter`** - изменение режима обхода для игр и других сервисов, использующих UDP и TCP на портах выше 1023.  
  **После изменения режима стратегию необходимо перезапустить.**  
  Текущее состояние (включено или выключено) отображается в скобках.
  - **`IPSet Filter`** - настройка режима фильтрации ресурсов из `ipset-all.txt`.  
  Этот параметр полезен при проверке ресурса, который без zapret работает.  
  В скобках показывается текущий режим:
    - `none` - ни один IP не проверяется
    - `loaded` - проверяется попадание IP в список
    - `any` - под фильтр попадает любой IP
  - **`Auto-Update Check`** - включение или отключение автоматической проверки обновлений.
  - **`Replace active fakes`** - замена выбранного активного фейка на другой файл из каталога `bin`.
  - **`Update IPSet List`** - загрузка актуального `ipset-all.txt` из репозитория.
  - **`Update Hosts File`** - обновление hosts <ins>для восстановления веб-версии Telegram и подключения к голосовым чатам Discord.</ins>
  - **`Check for Updates`** - ручная проверка доступных обновлений.
  - **`Run Diagnostics`** - поиск распространённых причин, из-за которых zapret не запускается или не работает.  
  В финале можно очистить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда возвращает неожиданно переставший работать клиент.
  - **`Run Tests`** - запуск проверки стратегий:
    - `Standard tests` - тестирование сайтов из `utils/targets.txt`
    - `DPI checkers` - проверка DPI у разных провайдеров, включая Cloudflare и Amazon


## ☑️ Частые вопросы и неполадки

### После запуска `general*` ничего не меняется

- При запуске стратегии отдельным bat-файлом, а не через service, должен появиться процесс winws.exe, видимый на панели задач.  
Если процесса нет, обратитесь к [#522](https://github.com/GeomancerBraid/zapret-discord-youtube/issues/522).

### Не подошла ни одна стратегия
- Откройте командную строку с правами администратора.
- Выполните команды по очереди:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`

- Перезапустите компьютер.

### Не открывается Telegram в браузере
Запустите **`service.bat`** и выберите **`Update hosts file`**. Если текущий hosts устарел, программа предложит обновить его вручную:  
  - Скопируйте весь текст из открытого блокнота.
  - Откройте текстовым редактором от имени администратора файл `hosts` в созданном каталоге.
  - Вставьте скопированный текст в конец `hosts` или замените прежние аналогичные записи.
  - Сохраните файл и проверьте подключение ещё раз. Если результата нет, убедитесь, что изменения действительно записались.

#### Работа не гарантируется. При отсутствии результата используйте [версию Telegram Desktop](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/GeomancerBraid/tg-ws-proxy) или любым публичным прокси.

### Обход не запускается или перестал работать

> [!IMPORTANT]
> **Стратегии могут со временем терять работоспособность.**
> Обнаружение используемой схемы может привести к тому, что ранее рабочая стратегия перестанет помогать.
> В репозитории есть много вариантов обхода. Если ни один не подходит, создайте новую стратегию на основе существующей, изменив её параметры.
> Описание параметров доступно в [документации](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Убедитесь, что `service.bat` -> `Run Diagnostics` не сообщает об ошибках.

- Проверьте, присутствует ли адрес ресурса в списке доменов или IP-адресов.

- Поочерёдно протестируйте другие стратегии, включая **`ALT`** и **`FAKE`**.

- Выполните полную переустановку по инструкции ниже.

- Дополнительная информация есть в [#765](https://github.com/GeomancerBraid/zapret-discord-youtube/issues/765).

### Как полностью переустановить или обновить проект?
- Сохраните добавленные вами ресурсы и данные.
- Перезагрузите устройство.
- Откройте `service.bat` -> `Remove Services`.
- Запустите `service.bat` -> `Run Diagnostics`; исправьте найденные ошибки и в конце выберите Y.
- Удалите старый каталог zapret.
- Скачайте свежую версию со [страницы релизов](https://github.com/GeomancerBraid/zapret-discord-youtube/releases), файл вида `zapret-discord-youtube-...`.
- Нажмите ПКМ по архиву и откройте свойства. Если внизу справа есть флажок разблокировки, включите его, нажмите применить и подтвердите кнопкой ОК.
- Распакуйте архив в новый каталог в корне диска, исключив пробелы, спецсимволы и кириллицу из пути.
- Запускайте разные скрипты `general` и проверяйте доступ к ресурсам. Если интернет-ресурсы не открываются, закройте программу через значок замка на панели задач и выберите другую стратегию.
- После нахождения рабочего варианта включите автозапуск через `service.bat` -> `Install Service` -> нужная стратегия.

### Игра или приложение не работает при включённом zapret

- В `service.bat` проверьте, что `Game Filter` имеет значение **`disabled`**, а `IPSet Filter` - **`none`**. Иначе фильтрация может затронуть неожиданные ресурсы.

### Античит обнаруживает WinDivert

- Ознакомьтесь с инструкцией: https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Windows 7 требует цифровую подпись драйвера WinDivert

- Замените `WinDivert.dll` и `WinDivert64.sys` в каталоге [`bin`](./bin) одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7).

### После удаления через [**`service.bat`**](./service.bat) WinDivert всё ещё есть среди служб

1. Получите имя службы командой в командной строке Windows, открытой через Win+R и `cmd`:

```cmd
driverquery | find "Divert"
```

2. Остановите службу и удалите её следующими командами:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не открывается <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте настройку [Secure DNS](#%EF%B8%8Fиспользование).
- Отключите блокировщик рекламы: известно, что YouTube начал с ними бороться.
- Перепробуйте остальные стратегии, особенно если раньше доступ был, а затем пропал.
- Дополнительные сведения: [#251](https://github.com/GeomancerBraid/zapret-discord-youtube/discussions/251).

### Не запускается <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что включён [Secure DNS](#%EF%B8%8Fиспользование).
- Сначала выясните, какая стратегия открывает сайт YouTube, и запустите её.
- Откройте `service.bat` -> `Run Diagnostics` и очистите там кэш Discord.
- Проверьте, появился ли доступ в приложении Discord после очистки кэша.
- Откройте Discord в браузере по адресу https://discord.com/app. Если веб-версия работает, можно временно пользоваться ею.
- Если браузерная версия тоже недоступна, снова проверьте все стратегии: YouTube и Discord могут работать на разных вариантах.
- Обсуждение проблемы: [#252](https://github.com/GeomancerBraid/zapret-discord-youtube/discussions/252).

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Установите [tg-ws-proxy](https://github.com/GeomancerBraid/tg-ws-proxy).
- Либо воспользуйтесь бесплатным MTProto-прокси из интернета.

### Игры не подключаются

Игр много, поэтому проверить и исправить каждую отдельно невозможно.

Обычно помогает следующая последовательность:
- через `service.bat` обновите ipset и включите `Game Filter`;
- если этого недостаточно, дополнительно активируйте `ipset any`.

Учитывайте, что `ipset any` может нарушить доступ ко многим сайтам. Не оставляйте этот режим включённым постоянно. Определите IP-адреса, используемые игрой, и добавьте их в `ipset-all.txt`.

Если проблема сохраняется, создайте обсуждение в разделе [Discussions](https://github.com/GeomancerBraid/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### В списке нет моей проблемы

- Создайте описание проблемы [здесь](https://github.com/GeomancerBraid/zapret-discord-youtube/issues).

## 🗒️ Добавление адресов других ресурсов

Дополнительные адреса для обхода добавляются в следующие файлы:
- **`list-general-user.txt`** - домены; поддомены учитываются автоматически.
- **`list-exclude-user.txt`** - домены, которые нужно исключить, например когда IP-сеть есть в `ipset-all.txt`, но конкретный домен фильтровать не требуется.
- **`ipset-all.txt`** - IP-адреса и подсети.
- **`ipset-exclude-user.txt`** - IP-адреса и подсети, исключаемые из обработки.
  - Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`.
